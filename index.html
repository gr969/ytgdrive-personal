YtGDrive Personal

A personal Windows command-line tool that downloads YouTube media the operator is entitled to download and uploads completed files to a chosen Google Drive folder.

The tool uses yt-dlp, FFmpeg, Deno, and rclone. It checks uploaded file sizes and checksums before removing local completed media. Failed uploads and partial downloads remain on the operator's computer for recovery.

This is a locally operated personal utility, not a hosted file-processing service. Google authorization is used by the local rclone installation.
