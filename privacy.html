Privacy policy

YtGDrive Personal · Updated 9 November 2026

Purpose and data access

YtGDrive Personal is a personal command-line utility run on its operator's Windows computer. It uses the Google Drive API through a local rclone installation to create destination folders, upload completed media, and read file identifiers, sizes, and checksums for verification. It reads the authenticated account email to check the intended account and folder access.

The Google Drive authorization scope permits viewing and managing files accessible to the account. The CLI directs its Drive operations to the configured destination folder. Authorization itself is broader than that folder.

Storage and transfers

OAuth credentials and tokens are stored in local rclone configuration. Download jobs, partial media, manifests, and download archives are stored on the operator's computer. Completed local media is deleted only after a verified upload. Uploaded files remain in the operator's Google Drive until the operator removes them.

The CLI communicates with YouTube and its media servers to download selected media, and with Google OAuth and Drive services for authorization and storage. It does not operate a separate application server, include analytics, sell Google user data, use that data for advertising, or send Drive contents to an application developer. This documentation website is hosted by GitHub Pages, whose own website privacy practices apply to visits.

Control and limited use

The operator can revoke access in Google Account third-party connections, remove local rclone credentials, and delete local job data or uploaded Drive files. Revoking access stops future authenticated requests but does not itself delete existing files.

YtGDrive Personal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This personal utility has no public account-registration service. For questions, use the support contact displayed on its Google OAuth consent screen.
